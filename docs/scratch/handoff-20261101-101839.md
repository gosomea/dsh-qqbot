- **只改 QQ 插件，不改 DSH 宿主源码、上游构建产物或日常实例。没有记忆服务。** 早期 Mem0、定制宿主、全量渠道事件和同 Session 动态更换预设方案已经作废，不可照旧计划继续实现。
- QQ 流水由插件账本保存，DSH 保存真实执行历史。不能承诺普通群消息全量进入原生日志、原生网页输入全部进入 QQ 队列；网页回答默认不外发，需显式发送已完成回答。
- “仅可查看”不等于只能读取工作区。不能证明权限继承的外部子 Agent 工具保持不可用。旧高级限制仍生效，但旧多层矩阵 UI 已删除。
- 普通非 @ 群消息本轮在 QQ 客户端可见，插件**未收到平台推送**；保存开关无法赋予平台接收权限。群聊默认仍需 @。
- “QQ 接口已接受”不是送达或已读；未知结果不自动重发。群被动回复窗口五分钟，查看网页不会续期。
- 原生空白 Session 的欢迎页可能暂不显示会话视图标签，从左侧对话菜单仍可进入设置。保留该公开接口限制，不通过修改宿主解决。
