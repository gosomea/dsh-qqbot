# QQ 独立左栏验收记录

日期：2026-10-31。范围：独立 QQ 导航、原生 Session 元数据与浏览器交互。本轮未修改后端行为、DSH 宿主或共享记忆功能，未提交、推送或发布。

## 实现结果

- QQ 入口切换为独立左栏模式，按群聊、私聊分组；返回工作区恢复原生导航。
- 点击群或联系人打开当前 Session，箭头独立展开历史。初始显示 5 条，更多按钮展开剩余历史；选择更旧历史时保证行存在于展开列表。
- Session 行显示原生标题及自身工作区；原生重命名与 QQ 备注分别保存。工作区变更创建新的当前 QQ Session，旧 Session 的 cwd 和历史不变。
- 右侧使用未修改的原生 Conversation、草稿、输入框、模型和权限控件；账号设置与每个 QQ 对话的设置分开。
- 搜索临时展开折叠分类；迟到的异步操作结果不能抢回新导航。旧 Agent 释放造成目录元数据缺失时，通过公开 Session 目录接口补读，每个缺失集合最多两次，不缓存伪造标题。

## 限制与保留状态

- 宿主没有公开的原生工作区列表排除接口，QQ Session 仍可能在普通工作区树出现；QQ 导航本身独立，不改写宿主树。
- 未修改既有 Session 的工作目录；工作区操作明确创建新的当前 Session。
- 已存在的合成环境没有“待授权且无 Session”的对话，相关 UI 分支由行为测试覆盖；浏览器使用无匹配搜索作为空列表负对照。
- 本轮没有发送新的真实 QQ 消息或调用模型。3192 的真实历史内容仅用于确认目录、当前映射和原生聊天显示，旧真实收发结果不计入本轮验收。
- 普通群消息是否由平台推送、完整消息接收范围不由本次左栏改动证明。共享记忆不在本次范围。
