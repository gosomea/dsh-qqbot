## 交互结果

- 当前 Session 由联系人行表示，不再重复渲染当前子卡片。无历史时不显示展开箭头。
- 历史初始显示 5 条，不包含当前 Session；更多历史可展开，外部打开更旧会话时显示目标。
- 一个 selectedSessionId 推导选中态。查看当前时高亮联系人；查看历史时只高亮历史行。
- 摘要隐藏重复的默认 QQ 标题，保留有意义的自定义标题。工作区显示短名称，完整 cwd 保留在提示中，历史不借用当前目录。
- 联系人菜单分组提供当前会话操作与 QQ 设置。重命名当前会话即使在浏览历史时也定位当前 Session；历史重命名仍定位历史。
- 点击可见历史搜索结果及恢复同一会话时保留筛选；外部切换其他历史目标时清除筛选并显示目标。
- 新建与工作区换新使用可取消导航意图、忙碌及映射变化校验，迟到结果不能抢回更新的导航。
