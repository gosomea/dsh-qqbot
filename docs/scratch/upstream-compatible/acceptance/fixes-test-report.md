# QQ Bot 功能与原生表单修复验收

日期：2026-10-31。对应 [功能审查](../../../decisions/upstream-compatible/reviews/functional-review.md) 和 [原生控件审查](../../../decisions/upstream-compatible/reviews/ui-consistency-review.md)。工作分支为 `codex/qq-upstream-compatible`，基线提交 `b021630`。本轮修改仍未提交，保留之前的工作树内容。

## 已处理的问题

| 审查问题 | 修复后的行为 | 验证 |
| --- | --- | --- |
| 旧草稿重新打开时套用新版本基线 | 缓存草稿和原始版本；发现冲突后保留草稿、阻止保存，显式重载才更新基线 | 真实 ReactDOM 测试、浏览器跨视图版本更新 |
| 自动换新被自身触发预约挡住 | 队列开始时只释放本条预约；后续预约、运行轮次和原生 Inbox 仍阻止不安全换新 | 入口回归、真实 stock Host 经 QQ SDK 入站验证 |
| 权限、沙箱、模板产生不可保存组合 | 一个转换函数返回可保存草稿或明确阻止原因；已知权限派生沙箱，自定义 Host ID 保留；变动立即预览 | 198 条转换路径调用真实后端校验器，真实组件测试 |
| 停用/准入部分完成却泛化报错 | 停用只修改此对话；全局放行持久化失败时保持停用，失败说明实际状态；连接待重载单独提示 | 真实路由、故障注入及组件反馈测试 |
| 所有者未加载被当成空名单 | 加载/失败和实际空名单分开；尚未读到有效名单时禁止编辑 | 真实组件测试 |
| 保存期间仍可改字段 | 锁定整张策略表单，失败保留草稿；目录读取失败可重试 | 真实组件异步测试 |
| 发送记录不更新、终态按钮重复提交 | 会话存储共享投递状态，发送后更新、开放手动刷新和 10 秒轮询；未知/失败操作终止，不重复请求 | 存储回归、浏览器配本地 QQ fixture |
| 手机与网页菜单列出未授权选项 | 复用服务端有效选择范围；空列表只继承 QQ 默认；普通成员不获得管理按钮，网页禁用未授权预设 | 命令回归、快照/实际 Modal+Menu 测试、浏览器 |
| 冷启动状态丢失当前会话信息 | `/bot-status`、`/bot-version` 先恢复已持久化映射，失败明确提示 | 回归、重启 stock Host 后执行状态命令 |
| 相同工作区仍承诺新建 | 当前工作区选项禁用；没有工作区时显示添加工作区提示；稳定 ID 提交，显示名使用公开 helper | 回归、浏览器菜单检查 |
| 多套弹窗和浏览器原生 select | QQ 备注、新建、预设和工作区共用操作表单；选择器、输入、按钮、开关及分段控件使用公开 DSH 组件；确认弹窗使用 Modal | 类型检查、真实组件、明暗主题及窄屏检查 |

域名白名单没有可靠执行适配，改为展示兼容状态及显式清除入口，不再提供误导性的正常编辑。未启用的 QQ 文件发送设置从表单移除，旧持久化字段保留。手机 `/preset reset`、账号默认值、记录保留期限、平台接收能力、闲置回收、SDK 超时和解绑影响均已校正说明；私聊使用通用对话措辞。

- 独立审查已复核权限转换、准入提示和有效预设授权，未留下确认的 P1/P2 问题。

## 隔离运行与浏览器

复用已登记的 `qqbot-commands` Home/profile、工作目录、数据和 3194/3195；QQ 目标只有合成身份，平台 API 由本地 fixture 提供。

1. 一条未 @ 的普通群消息保存且不启动模型；到达条数阈值后，下一条 @ 提问通过真实 SDK/中间件换新并完成一次真实模型回答。旧 Session 保留，其他三个对话映射不变。
2. 重启同一 stock Host，`/bot-status` 恢复相同当前 Session 和模型，没有新建会话。
3. 浏览器保留旧草稿后由另一入口保存新版本，重开能看到冲突且“确认保存”禁用；显式重载恢复可编辑状态。
4. 实际菜单禁用当前工作区和未授权的选择；方向键/Escape 可操作菜单，Escape 关闭菜单后焦点回到其触发按钮。菜单位于 portal，不被抽屉裁切。
5. 浏览器通过发送预览发起本地 fixture 失败请求，显示结果未知，提交按钮锁定；仅观察到一次失败请求。发送记录随新结果更新，无需重开页面；接口接受不宣称送达/已读。
6. 检查暗色、浅色、600px 窄容器、长名称和原生表单；主题已恢复“跟随系统”，视口覆盖已清除。

最后保留 3192 预览和已有扫码绑定。其当前会话、历史、策略、部署配置与本轮开始时一致。日常 3080 进程的 PID 和启动时间未变；宿主跟踪文件无修改，原有无关 `tmp-delivery/` 保留。合成测试 runner 已停止。

本轮没有重新发送真实 QQ 消息，没有重新扫码、更换凭据或解绑；历史真实收发结果不计入本轮验收。审批/平台流式/普通群消息推送等真实平台能力没有因为本地 fixture 通过而升级为已验证。
